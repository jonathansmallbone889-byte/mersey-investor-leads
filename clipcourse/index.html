    FAQ

    Why do I need to paste the transcript?

    Video platforms don't let websites download videos or captions directly. Copying the transcript takes a few seconds: on YouTube open the description, choose "Show transcript", select all and paste.

    Does it work without timestamps?

    Yes. Without timestamps, ClipCourse splits the transcript by topic and estimates the timing at an average speaking pace.

    What does AI mode change?

    The offline generator picks out key sentences and keywords to build the course. AI mode sends the transcript to Claude, which writes proper explanations, practice exercises and quiz questions. It uses your own API key.

    Can I share a course?

    Export it as Markdown for Notion, Google Docs or a blog, or use Print / PDF to save a clean handout.
